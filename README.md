## 🚀 Overview

An intelligent AI + IoT security system built using **Raspberry Pi 5, ESP32-CAM, OpenCV, Power BI, and Python** to provide real-time face recognition, intruder detection, motion monitoring, gas leakage detection, smart alerts, and analytics dashboards.

Unlike traditional CCTV systems, this platform actively detects threats, identifies family members, sends instant notifications, and generates security insights using Edge AI.

---

## ✨ Features

- 🔐 Real-Time Face Recognition
- 🚨 Intruder Detection & Alerts
- 🏃 Motion Monitoring using PIR Sensor
- ⛽ Gas Leakage Detection using MQ135
- 📱 Telegram Notification System
- 🔔 Automated Buzzer Warning System
- 📊 Power BI Analytics Dashboard
- 📈 R-Based Data Visualization
- 🌐 Edge AI Deployment on Raspberry Pi 5
