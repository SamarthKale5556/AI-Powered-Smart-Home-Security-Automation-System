## 🚀 Overview

Built an AI-powered smart home security platform that combines **Face Recognition, Intruder Detection, Motion Monitoring, Gas Leakage Detection, and Real-Time Alerting** using **Raspberry Pi 5, ESP32-CAM, OpenCV, Python, and Power BI**.

The system performs on-device AI inference, identifies authorized family members, detects unknown visitors, monitors environmental hazards, and instantly sends alerts through Telegram while maintaining analytics dashboards for security monitoring.

---

## ✨ Key Features

* 🔐 Real-Time Face Recognition
* 🚨 Intruder Detection with Snapshot Alerts
* 🏃 PIR-Based Motion Monitoring
* ⛽ MQ135 Gas Leakage Detection
* 📱 Telegram Notification System
* 🔔 Automated Buzzer Warning System
* 📊 Power BI Security Dashboard
* 🌐 Edge AI Deployment on Raspberry Pi 5
